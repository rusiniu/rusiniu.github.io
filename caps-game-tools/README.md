# 🎮 Caps Game Tools

Набор профессиональных инструментов для работы с открытыми данными игры **Caps Game**.

## 🛠️ Доступные инструменты

### 1. 📊 Аналитика рынка
Мониторинг текущих продаж фишек:
- Цены в TON (минимальная, максимальная, средняя, медианная)
- Распределение цен (гистограмма)
- Фильтрация по коллекции и редкости
- Сортировка по цене или номеру

### 2. 🖼️ Галерея коллекций
Просмотр всех фишек выбранной коллекции:
- Автоматическая генерация изображений (формат: `collections/{id}/{number}.png`)
- Информация о коллекции: тип, тираж, количество сожжённых, дата релиза
- Сетка 3×3 с ленивой загрузкой

### 3. 👤 Mad Caps Recruiter
Оценка коллекционера по TG ID:
- Общее количество фишек и распределение по редкостям
- Завершённые коллекции
- Боевая статистика (PvP/PvE/Madness/Exchange)
- Достижения и PvP ранговые очки
- Информация о премиум-статусе и энергии

### 4. 🔍 Caps Finder
- Поиск фишек по номеру:
- Просмотр всех фишек с указанным номером
- Информация о статусе (в продаже, в стейкинге, сожжена и т.д.)
- Данные о владельце (имя и ID)
- Информация о коллекции и редкости
- Группировка по статусам для удобного просмотра

## 🔗 API источники

Все данные получены из открытого Firestore API игры:
- `Static/CapsCollections` — список коллекций
- `Caps` — информация о фишках в продаже
- `Users/{id}` — данные игроков
